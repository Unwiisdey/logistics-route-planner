# 正式 UI 集成验证

验证日期：2026-10-23。原来的可选 Demo 已整合为项目根目录构建和启动的本地 Web 界面。

## 本机验证

- MSVC 19.29 x64、Release：标准根 CMake 构建通过，生成 CLI 和 logistics_ui_bridge。
- 通过系统 Python 3.13 运行 scripts/start_ui.py --no-browser：自动找到 Visual Studio CMake，完成构建、页面生成和本机服务启动。
- Release CTest：98 项全部通过。包含既有 96 项，以及 ui.bridge（6 个取送、窗口、载重、任务顺序和耗时锁定用例）、ui.http（4 个实际 HTTP 场景）。
- 正式页面浏览器检查通过：手动插单、拒单、真实取货配送、任务路径、暂停/推进、刷新状态保留和回放；320/390/1024/1280 宽度无整页横向溢出，无 JavaScript 运行错误。
- 原记录回放的离线操作、回退及深色模式检查通过。

当前运行保留单车、单个共享实例、本机服务、不持久保存订单的范围。道路在入边时锁定本段耗时；地图道路当前预计耗时与本车剩余耗时分开展示。

## 持续集成

GitHub 原 Ubuntu / Windows 流水线现在默认构建 UI 桥接，CTest 自动运行上述两套 UI 检查，并生成网页资产。远端每次运行的实际状态见仓库 Actions；本报告中的通过数字为本机验证结果，不代表尚未完成的远端运行。
