# v1.0.0 — 电商物流配送路径规划系统最终版

C++17 单车辆课程设计：有向图、配置加载、距离/成本规划、模拟时钟、车辆位置、硬窗口接单、动态取货与配送、载重、路况模拟、增量区间修复与动态图形回放。

本版加入有界最短路缓存和图版本失效，避免初始/动态订单候选反复计算相同两点最短路；已用开/关缓存集成测试验证行为一致。原有优先队列和目标提前停止保留。

验证：本地 Debug/Release 各 96 项 CTest 通过，23 项 Python 数据测试通过；一键演示和 PNG/GIF 已生成。1000 节点、4000 道路的重复查询基准从 480 次搜索降至 32 次；完整原始数据和五轮中位数见 `docs/reports/benchmark/`。

阅读顺序：README → docs/user-manual.md → docs/design.md → docs/api.md → docs/test-report.md。答辩材料见 docs/demo/README.md。运行 `python scripts/demo.py --plots --gif` 可重建演示。

GitHub 提供本标签的源代码压缩包。源代码构建需要 C++17 与 CMake 3.16+；Python/matplotlib 只用于可选绘图。仓库内 nlohmann/json 3.12.0 保留官方 MIT 许可证，其他第三方版本见说明。

范围：单车辆、启发式访问顺序，不保证全局最优；路况为模拟，界面回放导出数据；当前边/服务完成后衔接新路线；实际超时每单固定 10 分，可配置。运行中封路、多车、真实 GPS 和在线地图不属于本版。
