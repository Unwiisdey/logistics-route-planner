# 配置与演示数据

第 1 阶段仅保留目录和数据约定，没有可加载配置。第 2 阶段确定文件格式、实现解析器并提供演示数据。优先使用标准库可处理的简单格式；若选择 JSON，应明确解析库、版本与引入方式，不在当前阶段增加依赖。

配置应包括节点 ID、坐标、类型，道路起终点及距离/耗时/成本，车辆载重上限，以及订单配送点、货物量和时间窗口。系统还需要初始仓库、车辆初始位置及模拟开始时间，作为实现动态配送的设计字段。

演示数据至少包含 30 个节点、50 条有向道路，其中仓库至少 2 个、配送点至少 15 个、中转站至少 3 个；这三个最低数量之和为 20，仍需补足总节点数。双向道路须分别配置两个方向。

小规模算法验证数据可以低于上述规模；最终演示数据必须达标。构造演示网络时应保证计划配送点可达并能返回仓库，另准备不可达等异常场景。
