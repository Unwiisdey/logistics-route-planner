# 测试说明与后续计划

第 5 阶段使用 CTest 注册 69 项测试，无第三方 C++ 测试框架；另有 14 项 Python 标准库测试。C++ 检查通过显式异常和退出码实现，Release 下也保留。已在 Windows/MSVC x64 Debug 下全部通过。

- `graph_tests.cpp`：8 项测试，覆盖节点增删、入边/出边清理、边增删及方向、重复项和非法数值、邻接表确定性输出、三种矩阵权重、零权重与无边区分、路况数据更新、空图及复制独立性。
- `config_tests.cpp`：7 项测试，覆盖合法输入与默认值、语法与重复键、类型和缺失字段、节点/道路非法内容、加载失败不覆盖原图、文件错误与规模校验、示例数量和从每个节点出发的可达性。部分测试包含多个坏数据案例。
- `planning_tests.cpp`：12 项测试，覆盖两种 Dijkstra 权重、关闭道路、无路/同点、零权环、快照、溢出绕路、贪心行程、三项总量、子集/空任务/不同起点、途经配送点、载重和返仓失败、CSV 转义及过期计划拒绝、完整演示网络。
- Dijkstra 还在 20 张固定种子的 7 节点有向图上，与独立 Floyd–Warshall 的两种权重、全部源终点组合交叉验证，共 1960 组最短路检查，包含零权和关闭边。
- `simulation_tests.cpp`：11 项测试，覆盖时钟/跨天/非法值、车辆容量、边上位置和插值、早到等待、截止时刻开始卸货、固定处罚（迟到 1 分钟和更久处罚相同）、载重扣减、0.1/0.5/1/5/100 分钟步长一致、零耗时和空任务、重复通行不重复配送、过期/关闭路线拒绝、快照独立性及两种策略的 25 点仿真。
- `order_tests.cpp`：15 项测试，覆盖窗口和小数截止边界、独立订单、严格初始规划/同点多单、紧急优先、先卸货后取货、保护原截止时间、在途/等待/卸货衔接、连续待生效插单、拒绝不改变任务/车辆、返仓后接单、旧模式升级、步长一致、JSON 校验和路线版本导出。
- 应用：16 项测试，原 13 项加独立订单场景、硬窗口节点任务、缺少仿真模式时拒绝场景文件。
- `test_plot_network.py`：6 项 Python 标准库测试，检查 CSV 数据读取、损坏路线、关闭道路、总量不符、缺失字段和非有限坐标；无需安装 matplotlib。
- `test_plot_simulation.py`：8 项测试，检查车辆坐标、当前道路、时间倒退、伪完成、等待状态、非有限值，以及防止将动态版本错当固定路线；无需安装 matplotlib。

项目根目录构建完成后：

```sh
cd build
ctest -C Debug --output-on-failure
ctest -C Debug -R graph --output-on-failure
cd ..
```

第二条测试命令可选，只运行图模块。`config` 测试工作目录由 CMake 指定为源目录，应用测试读取构建目录的配置副本。

规划与导出测试运行于构建目录，临时 CSV 只写入构建目录的 `test_artifacts/`。Python 数据检查在项目根目录运行：

```sh
python -m unittest discover -s tests -p "test_plot*.py" -v
```

另已实际执行两种完整演示行程、车辆仿真与绘图脚本，检查生成图片和 GIF 帧，结果见 `docs/examples/` 与 `docs/examples/stage4/`。图形展示的人工检查不能代替算法数值测试；交互窗口的人工点击未作为自动化测试。

| 6 | 满足题目规模的完整演示；配置到规划再到动态事件的整体验证；异常反馈；文档与实际行为一致 |
