# 验证计划

当前阶段没有业务算法，也没有自动化测试目标。验证范围是 CMake 配置成功、C++17 编译通过、程序运行并输出阶段说明。以下为后续计划，不表示测试已执行。

| 阶段 | 验证重点 |
| --- | --- |
| 2 | ID 唯一性、节点和边增删、删除节点后的关联边清理、非法引用、负权重、配置错误、演示数据规模 |
| 3 | 用可手算小图核对 Dijkstra；有向不可达；距离与成本策略差异；从仓库出发并返回；空订单；载重不足；界面方向和高亮 |
| 4 | 提前到达等待、截止时刻送达、超时记录；暂停和推进；节点及道路上的位置；紧急订单可行/冲突；已完成订单不重复执行 |
| 5 | 低于、等于和高于 20% 的边界；连续拥堵更新；与当前路线无关的道路变化；车辆在途时重规划；时限与界面同步 |
| 6 | 满足题目规模的完整演示；配置到规划再到动态事件的整体验证；异常反馈；文档与实际行为一致 |

算法测试应验证已知正确结果和业务约束。启发式访问顺序测试不能仅因得到一条路线就声称已证明全局最优。未来可用 CTest 组织测试，无须立即引入第三方测试框架。
